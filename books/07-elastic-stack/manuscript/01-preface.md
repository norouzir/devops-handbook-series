# About This Book

This book is the seventh volume of the DevOps Handbook Series. *Docker for DevOps Engineers* answered how to package an application, *Kubernetes for DevOps Engineers* answered how to run it, *GitHub Actions for DevOps Engineers* answered how to build, test, and ship it, *Ansible for DevOps Engineers* answered how to configure it, *Terraform for DevOps Engineers* answered how to provision the infrastructure underneath it, and *Prometheus & Grafana for DevOps Engineers* answered how to measure the platform with metrics. This volume answers the two questions metrics deliberately leave open: *what exactly happened* - the log line, the stack trace, the request body behind the spike on the graph - and *how do I search all of it*, across every host and every service, in under a second. The Elastic Stack is the most widely deployed answer to both, and this book builds the search half of the same loop the metrics book opened: metrics tell you *where* to look; search tells you *what* you are looking at.

The book is organized in two parts. Part I, Elasticsearch Foundations, builds the engine and the muscle memory: the landscape and the inverted index that makes search fast, cluster architecture with nodes and shards, a running Elasticsearch plus Kibana sandbox in Docker Compose, data ingestion with Elastic Agent, Filebeat, and Logstash, mapping and text analysis, the Query DSL in two passes - search in one chapter, aggregations in the next - and ES|QL, the piped query language that has become the fastest way to interrogate the index. Part II, Production Elastic, is the working platform team's part: Kibana data views, dashboards, and KQL; data streams and Index Lifecycle Management; scaling - shard strategy, heap, watermarks, and query performance; security with TLS, roles, and API keys; snapshots and Snapshot Lifecycle Management; and the operational surroundings - ECK on Kubernetes, Fleet at scale, APM, alerting, and the bridge to Grafana for teams that run both stacks. The parts are sequential; Part II assumes only Part I and the earlier chapters of Part II itself.

The content reflects the platform as of October 2026. The current stable line is Elasticsearch 9.5, with Kibana 9.5 and Logstash 9.5 on the same version train and the 8.19 branch maintained for upgrades. Three generational changes shape the examples in this book. First, Elasticsearch 9.0 (April 2025) moved the engine to Apache Lucene 10 and the 9.1 release made BBQ - Better Binary Quantization - the default for new vector fields, cutting vector memory by an order of magnitude; the stack you are learning is the one that also powers the current generation of AI-era search, retrieval-augmented generation, and agent tooling that Elastic ships around it. Second, **ES|QL** - the piped query language that went generally available in 8.14 and has grown rapidly since - is treated as a first-class citizen of the book, not a footnote: Chapter 8 teaches it end to end, and later chapters reach for it whenever it is the shorter path. Third, ingestion has consolidated: **Elastic Agent with Fleet** is Elastic's strategic, recommended way to collect logs and metrics, while the Beats (Filebeat, Metricbeat) remain fully supported where their capabilities are still needed - the book teaches the Agent-first path and explains honestly when a Beat is still the right tool. Licensing deserves one sentence here because it changed twice in recent memory: since August 2024, Elasticsearch and Kibana are published under your choice of three licenses - Elastic License 2.0, SSPL v1, and AGPLv3 - which restored an OSI-approved open-source option alongside the source-available licenses. Where a capability is experimental, plan-gated, or enterprise-only, the book says so explicitly instead of presenting the happy path as universal.

Three conventions run through the book. Commands, configuration, JSON, and query snippets appear in monospaced blocks, and every example is shown complete enough to paste into Kibana Dev Tools or a shell and run - the Docker Compose stack in Chapter 3 grows with you through the book. Technical terms such as index, shard, mapping, data stream, and policy are kept in English and capitalized when they name a platform concept, matching how professionals speak. Notes marked **Best practice** condense operational wisdom, while **Watch out** boxes flag the mistakes that cause the most production pain, from unbounded dynamic mapping through oversharded clusters to snapshot repositories that were never restore-tested. Because the book targets practitioners, full labs appear in the five chapters where hands-on practice changes the most: a working Elasticsearch plus Kibana stack with your first documents, shipping Nginx logs through Filebeat with parsed fields, building a structured log search with the Query DSL, a Kibana analytics dashboard over aggregations, and a snapshot policy with a rehearsed restore drill. The appendices compress the rest into a desk reference: a Query DSL, API, and ES|QL cheat sheet, a set of starter configurations you can copy into a repository, and a troubleshooting guide organized by symptom.

Every chapter closes with a *See also* list, every internal reference is a live link, and the Part dividers, table of contents, and headings are navigable in all three editions - in the PDF the contents carry computed page numbers and the heading tree appears in the outline panel.
